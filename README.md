## How It Works

1. Select a category.
2. Choose the unit you want to convert from.
3. Enter a value.
4. Choose the unit you want to convert to.
5. The result is calculated automatically.
6. Use the Swap button to switch the units.
7. Use Clear to remove the entered value.

## Notes

The converter works completely in the browser and does not need a backend.

The currency converter currently uses fixed exchange rates, so currency values may not match the latest market rates.
